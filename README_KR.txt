Real CRT Phosphor v1.4.3  — RetroArch용 CRT 셰이더 (slang)
제작: 건군 (기획·방향·실기 테스트·튜닝)
AI 저작물 표시: 코드 대부분을 AI(Claude, ChatGPT)가 작성했습니다. 자세한 내용은 LICENSE_KR.txt

■ 이 셰이더는
  실제 CRT TV를 가까이서 찍은 사진처럼, 화면이 RGB 형광체 줄로만 빛나게 만듭니다.
  - 바탕 그림 위에 마스크를 덮는 방식이 아니라, 빛이 오직 R·G·B 줄에서만 나옵니다.
  - 밝은 색의 줄은 굵어지고 어두운 색의 줄은 가늘어집니다 (색마다 줄 모양이 달라짐).
  - 아주 밝은 곳에서는 줄들이 빛 덩어리로 녹아듭니다.
  - 줄이 굵어져도 빛의 총량은 유지되어 어두워지거나 탁해지지 않습니다.

■ 설치
  1) real-crt-phosphor 폴더를 RetroArch/shaders/shaders_slang/ 안에 넣습니다.
  2) 비디오 드라이버는 Vulkan(권장) 또는 glcore, D3D11 등 slang을 지원하는 것.
  3) 게임 실행 → Quick Menu → Shaders → Load
     - 바로 써 보기: real-crt-phosphor.slangp
     - 추천 설정:   presets/4K/ (4K 모니터), presets/Ally/ (1080p 휴대기기)
  4) 마음에 들면 Save → Save Core Preset (기종마다)

■ 보너스: GBA 색 보정 (GBA Comfort Color) — presets/GBA/
  GBA 게임은 강한 형광색을 많이 써서, 요즘 화면에서 에뮬레이터로 하면 우주가 새파랗고 초록이 형광색으로 보여 눈이 피로합니다.
  GBA 보너스 프리셋은 그런 진한 색을 눌러서 편하게 볼 수 있게 합니다.
  - 세기 3가지: 약(light) / 중(medium, 잘 모르겠으면 이것) / 강(strong, 슈퍼로봇대전 A처럼 형광색이 가득한 게임)
  - 색만 (1패스, 휴대기기용): presets/GBA/gba-light, gba-medium, gba-strong.slangp
  - 색 + CRT (15패스): presets/GBA/gba-crt-light, gba-crt-medium, gba-crt-strong.slangp
  - 따로 설치할 것 없음 (real-crt-phosphor 폴더 안에 들어 있음). 자세한 내용은 presets/GBA/README_KR.txt

■ v1.4.3 수정
  1) 고해상도 화면이 다시 선명해졌습니다 (PS2, PS1 640x480, ShaderGlass 캡처)
     v1.4.1은 가로 320보다 넓은 화면을 모두 256 화면만큼 부드럽게 만들었습니다. 슈퍼패미컴 512 모드(256 그림을
     가로로 두 배 늘린 것)에는 맞았지만, PS2 640x448 같은 진짜 고해상도 화면은 글자를 읽기 어려울 만큼 흐려졌습니다.
     이제 세로 288줄 이하(240p급)이면서 가로 321~599인 화면(슈퍼패미컴 512, PS1 368~512)만 v1.4.1 방식을 쓰고,
     그보다 큰 화면(480줄급, 가로 600 이상, ShaderGlass로 작은 창을 잡은 400x300 같은 화면)은 다시 v1.4 방식을 씁니다.
     - 가로 320 이하: v1.4·v1.4.1과 동일 / 슈퍼패미컴 512(성검전설3 대화창 등): v1.4.1과 동일
     - PS2, PS1 640x480·368x480 메뉴, ShaderGlass 캡처: v1.4와 픽셀 단위로 동일
     제보해 주신 레딧 사용자(ROG Ally에서 PCSX2 + ShaderGlass)께 감사드립니다.
  2) PSP 4배 내부 해상도(1088줄)에서 주사선 수가 틀리던 문제 수정
     1088 / 240 = 4.5라 5배로 잘못 읽어 주사선이 272줄이 아니라 218줄로 그려졌습니다.
     이제 272의 배수(1088·1360·1632)는 PSP 줄 수로 읽어 272줄이 맞게 나옵니다. 1배·2배·3배 PSP는 그대로입니다.
  3) 보너스: GBA 색 보정 프리셋 (위 항목)

■ v1.4.1 수정: 게임 도중 화면 폭이 바뀌어도 화면이 갑자기 선명해지거나 오른쪽으로 밀리지 않습니다
  일부 게임은 플레이 중에 화면 가로 해상도를 바꿉니다. 예를 들어 성검전설3(슈퍼패미컴)는
  대화창이 열릴 때마다 가로 256픽셀에서 512픽셀로 바뀝니다. 이전에는 빛 번짐(Glow)과 가로 번짐을
  게임 픽셀 단위로 계산하고 상한을 두었기 때문에, 512 모드에서는 화면상 크기가 약 60%로 줄어
  화면이 갑자기 선명해지고 블룸이 사라진 것처럼 보였습니다. 또 오른쪽 끌림 번짐도 게임 픽셀 간격으로
  만들어져서, 촘촘한 512 격자에서는 조금 길게 잡혀 화면이 오른쪽으로 움직이는 것처럼 보였습니다.
  이제는
  - 빛 번짐이 입력 해상도와 상관없이 화면에서 같은 크기를 유지하고,
  - 넓은 모드(320 초과)에서는 신호 필터(부드러움, 색 번짐, 오른쪽 끌림)를 256 필터 그대로 늘려 써서
    256 화면과 같은 크기, 같은 위치로 나옵니다.
  실제 CRT에서도 이 번짐들은 브라운관 유리와 아날로그 신호에서 생기므로 게임 해상도에 따라 달라지지 않습니다.
  - 가로 320 이하 게임(대부분의 슈퍼패미컴·메가드라이브·아케이드·PS1 게임): v1.4와 픽셀 단위로 동일
  - 더 넓은 화면(PS1 368·384·512·640, 슈퍼패미컴 512): 256 화면에 가깝게 부드러워짐
  - 가로 512 화면의 글자도 그림처럼 조금 부드러워지지만 잘 읽힙니다.
  - 1~2픽셀짜리 아주 작은 무늬는 256과 512의 픽셀 격자가 어긋나 있어 완전히 같아질 수는 없지만,
    차이는 몇 % 안쪽입니다 (4K와 ROG Ally에서 확인).
  폴더를 덮어쓰기만 하면 됩니다. 기존 프리셋과 게임 프리셋은 그대로 쓸 수 있습니다.

■ v1.4 새 기능: 3D 게임 업스케일 전용 프리셋 (가볍고, 화면은 그대로)
  PS1·PSP·N64·PS2처럼 에뮬레이터 내부 해상도를 2·3·4배로 올려 쓸 때 고르세요.
  - presets/4K/4k-up2x · 4k-up3x · 4k-up4x        : 4K 모니터용
  - presets/Ally/ally-up2x · ally-up3x · ally-up4x : ROG Ally·1080p용
    예) Ally에서 PS1을 2배로 → presets/Ally/ally-up2x.slangp
  - 기종별 느낌(ps1·psp 등)이 필요하면 웹 미리보기에서 맞춘 뒤 "업스케일 전용으로 저장"을 고르세요.
  - (참고) real-crt-phosphor-up2x / up3x / up4x.slangp 는 위 프리셋이 가리키는 바탕 파일입니다.
  · 첫 단계에서 N×N 평균을 낸 뒤 화면을 원래 해상도로 줄여서 넘깁니다.
    뒤 단계 계산과 중간 버퍼가 1배 수준으로 줄어, 3배·4배에서 프레임 드랍과
    게임이 해상도를 바꿀 때(전투 진입 등) 생기던 순간 멈춤·소리 끊김이 줄어듭니다.
  · 결과는 1배 원본과 픽셀 단위로 같습니다 (일반 프리셋으로 업스케일 화면을 돌릴 때보다 오히려 더 정확).
  · 2D 게임(NES·SFC·메가드라이브·오락실)은 기존 프리셋 그대로 쓰면 됩니다.
  · 추천: 3D 게임은 내부 해상도 2배 + up2x. 계단 줄이는 효과는 거의 그대로이고 가장 가볍습니다.
    ROG Ally 같은 휴대기기는 3배부터 에뮬레이터 자체가 GPU를 대부분 써서 프레임이 떨어질 수 있습니다.
  · 내부 해상도를 바꾸는 게임에만 Save Game Preset 으로 저장해 두면, 다른 게임에 잘못 적용될 일이 없습니다.
  · 내부 해상도 배율과 프리셋 배율이 같아야 합니다 (3배 화면엔 up3x).
  · 웹 미리보기: 3·4배 화면을 넣고 .slangp 저장을 누르면 업스케일 전용 저장이 자동으로 선택됩니다.

■ v1.3 새 기능: 화면 곡률 (선택, 기본 꺼짐)
  옛날 브라운관 유리처럼 화면 가운데가 볼록하게 휘는 효과입니다.
  메뉴 맨 아래 [ SCREEN CURVATURE ]
  - Tube curvature   : 휘는 정도 (0 = 평면, 기본 0). 0.05 살짝 / 0.15 보통 / 0.3 많이
  - Rounded corners  : 모서리 둥글기 (곡률을 켰을 때만)
  - Edge darkening   : 가장자리 어두워짐 (곡률을 켰을 때만)
  - Mask follows curvature : 1이면 RGB 줄무늬도 같이 휨 (기본 0). 실제 브라운관에 더 가깝지만
                             1080p에서는 물결무늬(모아레)가 보이고, 4K에서는 훨씬 덜함
  · 스캔라인과 RGB 줄을 그리기 "전에" 휘기 때문에, 곡률 셰이더를 따로 붙일 때 생기는 모아레가 없습니다
  · 기본은 RGB 줄무늬가 화면에 곧게 서 있고, 그림과 스캔라인이 휩니다
  · 곡률 0이면 v1.2와 완전히 같은 화면입니다
  · 슬롯 마스크의 Slot lock(스캔라인 맞춤)은 곡률이 클 때 살짝 어긋날 수 있습니다

■ v1.2 새 기능: 형광체 잔광 (움직임 잔상)
  움직이는 물체가 지나간 자리에 형광체 빛이 꺼져 가며 남는 효과입니다. 기본값은 꺼짐.
  메뉴 맨 아래 [ PHOSPHOR AFTERGLOW ]
  - Afterglow strength : 잔상 세기 (0 = 꺼짐)
  - Afterglow time     : 잔상이 눈에 10% 밝기로 보일 때까지의 시간(ms). 클수록 꼬리가 길어짐 (기본 20)
  - Red lasts longer   : 빨강 형광체가 몇 배 오래 남는지. 클수록 꼬리가 붉어짐 (기본 1.2)
  추천: 세기 0.4 · 시간 20 · 빨강 1.2 (실제 CRT에 가까운 은은한 붉은 끌림)
        세기 0.8 · 시간 200 · 빨강 2 (기억 속 과장된 꼬리)
  · 멈춰 있는 화면은 전혀 바뀌지 않습니다 (밝아지거나 흐려지지 않음)
  · 잔상은 원래 그림보다 어둡게, 점점 꺼지며 남습니다
  · 게임 원래 해상도 단계에서 계산해서 부담이 거의 없습니다
  · 시간은 60fps 기준입니다. 실제 가정용 CRT의 잔광은 이보다 훨씬 짧아서, 이 값은 "기억 속 느낌"을 위한 취향 설정입니다
  · 웹 미리보기는 정지 화면이라 잔상이 보이지 않습니다. RetroArch에서 움직이며 맞추세요

■ v1.1.1 변경점 (속도 개선, 화면은 그대로)
  아이패드·스마트폰 같은 휴대기기 GPU에서 느리던 부분을 고쳤습니다.
  - 감마 변환(pow)을 화면 해상도 단계에서 게임 원래 해상도 단계로 옮김
    → 화면 픽셀마다 하던 pow 32번이 0번 (Signal 단계는 실수 버퍼로 선형값 저장)
  - 밝은 곳 빛 덩어리 계산을 exp 1번 + 보정식으로 간소화 (덩어리가 1.2px 이상일 때)
  - 화면 단계의 특수 함수(pow·exp 등) 계산량 약 1/4로 감소
  - 이전 버전과 결과 차이: 픽셀당 최대 2/255 (눈으로 구별 불가)
  ※ 기존 프리셋·게임 프리셋은 그대로 쓰면 됩니다. 폴더째 덮어쓰기만 하세요.

■ 두 가지 마스크 (v1.1 새 기능)
  Aperture Grille  세로 RGB 줄. 소니 계열 TV 느낌. 기본값.
  Slot Mask        RGB 묶음이 짧은 칸으로 끊기고, 옆 묶음과 반 칸씩 엇갈림(벽돌 배치).
                   일반 가정용 브라운관 TV 느낌.
  Shader Parameters 의 "Mask type: 0 Grille / 1 Slot" 으로 바로 바꿀 수 있습니다.

■ 추천 프리셋
  presets/4K/   (32인치 4K 모니터)     presets/Ally/ (ROG Ally 1080p)
    *-sfc / *-ps1 / *-ps2 / *-psp            Aperture Grille, 피치 4.5
    *-sfc-slot / ... / *-psp-slot            Slot Mask, 피치 3
    *-ps2-2d                                 PS2 2D 게임용, 피치 1.5
  자세한 구조와 게임별 조정법: presets/프리셋_사용법.txt

■ 자주 만지는 값
  RGB triad pitch px       RGB 줄 묶음 간격. 0 = 자동. Grille은 4.5, Slot은 3 추천
                           (슬롯은 피치가 크면 틈이 굵어져 무늬가 날카롭게 보임)
  Slot gap fraction        슬롯 틈 비율 (기본 0.22). 높이면 끊김이 뚜렷해짐
  Slot gap depth           슬롯 틈 진하기 (기본 0.6). 1.0 = 틈이 완전히 검게 꺼짐(디더처럼 보이기 쉬움)
                           낮출수록 틈에 빛이 조금 남아 벽돌 구조는 보이되 체크무늬가 약해짐.
                           평균 밝기는 자동 보정되어 값을 바꿔도 화면이 어두워지거나 밝아지지 않음
  Slot gap edge softness   슬롯 틈 가장자리 부드러움
  Slot follows scanlines   1(기본) = 슬롯 칸을 스캔라인에 맞춤. 틈이 줄 사이 어두운 곳에 오고
                           스캔라인과 엇갈리는 물결무늬가 생기지 않음. 0 = 스캔라인과 따로(물결 가능)
  Slot height in scanlines 슬롯 한 칸의 높이(스캔라인 수, 기본 2)
  Slot vertical pitch adjust  슬롯 상하 간격 미세 보정 (기본 1.0, 0.5~2.0)
                           1.0 = 스캔라인에 정확히 맞춤. 1.0에서 멀어질수록 칸이 길어지거나 짧아지는 대신
                           스캔라인과 조금씩 어긋나 옅은 물결이 다시 생길 수 있음. 0.9~1.1 사이부터 시험 권장
  Slot straight sides      1(기본) = 칸 옆면을 곧게. 줄 굵기가 스캔라인 사이에서 잘록해져
                           뼈다귀·육각형처럼 보이던 현상을 막음
  Horizontal softness      가로 번짐 (게임마다 조정 포인트)
  Vertical softness        세로 번짐 (스캔라인을 부드럽게)
  Convergence error        R은 왼쪽, B는 오른쪽으로 살짝 어긋남. 0.4~0.6이면 옛날 TV 맛
  Brightness               4K 밝은 모니터는 1.0 전후

■ 참고
  - 스크린샷을 축소해서 보면 RGB 줄이 사라지거나 무늬가 생깁니다. 원본 크기로 보세요.
  - 피치를 3 미만(예: 1.5)으로 두면 RGB 줄 대신 아주 고운 색 섞임으로 작동합니다.
    PS2 2D 게임에서는 도트 가장자리가 부드러워져 업스케일한 듯한 효과가 납니다(*-ps2-2d).
  - Slot follows scanlines 를 0으로 두면 슬롯이 스캔라인과 따로 계산되어 물결무늬가 생길 수 있습니다.
