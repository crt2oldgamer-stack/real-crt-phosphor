Real CRT Phosphor 미리보기 (v1.1 셰이더용)
==========================================

RetroArch 스크린샷 한 장으로 Real CRT Phosphor 셰이더 값을 바로 바꿔 보고,
마음에 드는 값을 .slangp 프리셋으로 저장하는 웹페이지입니다.
crt-preview.html 파일 하나만 있으면 되고, 인터넷 연결 없이 브라우저(Chrome·Edge·Firefox)에서 열립니다.
이미지는 브라우저 밖으로 나가지 않습니다.

■ 바로 써 보기
  열면 내장된 샘플 그림(320×240)이 바로 셰이더가 적용된 상태로 뜹니다. 내 게임 화면은 안내 창이나 '게임 화면 열기'로.
  샘플 그림은 이 툴을 위해 새로 만든 오리지널 그림이라 누구나 자유롭게 써도 됩니다.
  (노을 그라데이션·디더, 작은 캐릭터, 물결, 글자, 컬러바·회색 단계·1픽셀 줄·메가드라이브식 디더·피부톤)

■ 스크린샷 찍는 법
  1. RetroArch를 전체화면으로 하고 셰이더를 끕니다 (Quick Menu → Shaders → Video Shaders 끔).
  2. 스크린샷을 찍습니다. 이 파일을 '게임 화면'으로 엽니다.
     → 확대된 화면에서 원래 게임 해상도를 자동으로 찾고, 결과 크기도 이 스크린샷에 맞춥니다.
  3. (선택) 같은 장면을 셰이더를 켜고 한 장 더 찍어 '비교용 셰이더 화면'으로 엽니다.
     → RetroArch 결과와 나란히 비교하거나, '쓰인 프리셋 찾기'로 어떤 프리셋인지 확인할 수 있습니다.
       프리셋과 함께 바꿔 쓴 RGB 줄 간격(피치)과 Convergence 값도 화면에서 재서 찾아 줍니다.
  * PrintScreen 후 툴에서 Ctrl+V 로 붙여 넣어도 됩니다. 모니터 양옆의 검은 테두리는 자동으로 잘라 냅니다.
    (화면이 검게 찍히면 RetroArch를 '창 모드 전체화면'으로. 모니터가 여러 대면 Alt+PrintScreen 후 '게임 영역 자르기'.)
  * 창 모드라면 RetroArch 스크린샷 기능(기본 F8)이 가장 편합니다. 창 테두리 없이 게임 화면만 저장됩니다.
  * 셰이더 끈 화면과 켠 화면은 같은 프레임일수록 비교가 정확합니다 (일시정지 후 찍기 권장).

■ 쓰는 법
  - 내 모니터 해상도를 알아서 읽고, 그 화면 크기와 맞는 프리셋(1080p면 ally-, 1440p·4K면 4k-)으로 시작합니다.
  - 왼쪽 위 '간단히/전체': 간단히는 자주 쓰는 값 8개만, 전체는 모든 값을 보여 줍니다.
  - ↶ ↷ (Ctrl+Z / Ctrl+Shift+Z): 되돌리기·다시 하기. '전체 초기화'는 지금 프리셋 값으로 되돌림 (이것도 되돌리기 가능).
  - 보기 '밀어서 비교': 가운데 노란 막대를 좌우로 밀면 왼쪽은 원본, 오른쪽은 결과.
  - '도구' 메뉴: 화면 크기·입력 설정, 게임 영역 자르기, 쓰인 프리셋 찾기, 설정 공유 링크 복사.
    공유 링크를 연 사람의 툴에는 같은 프리셋과 값이 그대로 열립니다 (웹에 올린 주소에서 복사해야 함).
  - 위쪽 '기종'에 찾아낸 기종과 해상도가 표시됩니다. 틀리면 직접 고르세요.
    SFC·PS1·PS2·PSP처럼 전용 프리셋이 있는 기종은 그 프리셋으로 바뀝니다 (값을 이미 바꿨다면 그대로 둠).
  - 창 테두리나 여백이 같이 찍혔다면 '게임 영역 자르기'로 게임 부분만 드래그합니다.
    대충 드래그해도 가장자리는 가까운 경계선에 자동으로 맞춥니다.
  - 크기가 알려진 기종과 맞지 않으면 어느 기종인지 묻습니다. 큰 현대 게임 화면이면 줄 수(240·480·540·720)도 여기서 고릅니다. 화면 일부만 찍혔다면 기종을 고르면
    모자란 곳을 검정으로 채워 그 기종의 전체 화면으로 만듭니다.
  - 시작 프리셋을 고르고 왼쪽 수치를 바꿉니다. 바꾼 항목은 주황색으로 표시됩니다 (↺ 로 되돌리기).
  - 배율 1:1 = RetroArch 화면 1픽셀이 모니터 1픽셀 (전체화면 스크린샷을 이미지 뷰어 100%로 보는 것과 같음).
    1:1 이상에서 RGB 줄을 정확히 볼 수 있고, 윈도우 배율(150% 등)은 자동으로 보정합니다.
  - '⛶ 실제 화면': 브라우저 전체화면으로 바꿔 RetroArch 전체화면과 같은 크기로 봅니다. Esc로 나갑니다.
  - 아래 정보 줄: 셰이더가 읽는 스캔라인 수, 평균 계수, RGB 묶음 폭, 게임 픽셀 하나가 몇 묶음인지.
  - .slangp 저장: 넣을 위치를 고릅니다.
      · RetroArch의 shaders 폴더 (추천) — 그 폴더에 파일만 넣으면 끝. 프리셋 값까지 전부 파일에 들어 있음
      · shaders/shaders_slang 폴더 — 위와 같고 한 단계 안쪽
      · presets/4K·presets/Ally 폴더 — 고른 프리셋을 가리키고 바꾼 값만 적음 (그 프리셋 옆에 있어야 함)
    그다음 RetroArch에서 Quick Menu → Shaders → Load로 고르고, 계속 쓰려면 Save Game Preset(또는 Core Preset).
    shaders 폴더 위치는 RetroArch의 Settings → Directory → Video Shaders 에 나옵니다.
    Save Game Preset 을 한 뒤에는 넣은 파일을 지우거나 이름을 바꾸지 마세요 (게임 프리셋이 그 파일을 가리킴).
  - .slangp 불러오기: 기존 게임 프리셋을 열어서 이어서 조정할 수 있습니다.
  - 이미지 저장 ▾
      · 결과 전체: 셰이더 결과를 RetroArch 화면 크기 그대로
      · 비교 이미지: 지금 보고 있는 부분을 원본 | 결과로 나란히, 프리셋·해상도 라벨 포함 (게시판용)
      · 보이는 화면 그대로: 밀어서 비교 막대까지 지금 화면 모습 그대로 1:1
  - 세로 아케이드 게임은 자동 감지됩니다 (화면 크기·입력 설정에서 바꿀 수 있음).
  - 오른쪽 위 버튼으로 한국어/English 전환.

■ 웹에서 받은 이미지를 넣으면
  - 원래 해상도 PNG, 깨끗하게 확대된 PNG : 정확히 판별 (작은 이미지는 4K 높이로 그림)
  - JPEG로 압축된 확대 이미지 : 해상도를 추정 (정보 줄에 표시)
  - 흐리게 확대된 이미지, 이미 CRT 효과가 들어간 사진 : '도트가 깨끗하지 않음' 경고, 240줄로 추정.
    CRT 사진은 효과가 두 번 겹칩니다. 위쪽 '기종'에서 고르면 그 해상도로 맞춥니다.
  가장 좋은 입력은 에뮬레이터에서 직접 찍은 스크린샷입니다.

■ 현대 게임을 브라운관에 띄워 보기 (재미용)
  리메이크 같은 고해상도 화면을 넣고, 위쪽 '기종' → '현대 게임·사진'에서 줄 수를 고릅니다.
  240줄(옛날 TV) / 480줄(방송용·PVM) / 540줄(고해상도 CRT) / 720줄(아주 선명한 CRT).
  화면을 그 줄 수로 줄인 다음 그만큼의 스캔라인으로 그립니다 (Scanlines·평균 계수는 자동 설정).

■ RetroArch와 같은지 확인한 결과 (4K 전체화면 캡처 기준, 0~255 픽셀 평균 차이)
  - PS1 레이스톰 + 4k-ps1        : 0.12 (99% 픽셀이 1단계 이내)
  - MAME 라이덴2(세로) + 4k-ps1-slot : 0.11
  - PS1 파이널 판타지 VII (ROG Ally 1080p, 368폭 화면) : 1.36 — 프리셋 찾기가 피치 4를 스스로 찾음
  - NES 마리오(NTSC 필터) : 평평한 곳 0, 무늬 부분은 두 캡처의 프레임이 달라서 차이

■ 알려진 점
  - 실제 그래픽카드에서의 속도는 아직 확인 전입니다 (작업 환경은 소프트웨어 렌더링).
  - 셰이더 끈 화면을 GPU Screenshot 방식으로 찍으면 RetroArch가 확대한 화면이 저장됩니다.
    이 툴은 그 확대 화면에서 원래 해상도를 되찾기 때문에 문제없습니다.
  - PSP 등을 업스케일했다면 정보 줄의 스캔라인 수를 확인하고, 필요하면 INPUT 항목을 직접 넣으세요.

■ 셰이더를 고친 뒤 툴 다시 만들기 (개발용)
  dev/build.py 가 셰이더 폴더의 .slang 파일과 프리셋을 읽어 crt-preview.html 을 새로 만듭니다.
    python dev/build.py <real-crt-phosphor 폴더> crt-preview.html
  (Python 3만 있으면 됨. 화면 디자인·문구는 dev/template.html, 샘플은 dev/sample_320x240.png)
